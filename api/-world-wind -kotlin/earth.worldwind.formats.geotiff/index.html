object GeoTiffWriter

Cross-platform TIFF writer for the engine's elevation cache. Produces a minimal but spec-compliant baseline TIFF: little-endian header, single strip, uncompressed, BlackIsZero photometric, single sample per pixel, 32-bit IEEE float values. Reads back cleanly through GeoTiffReader and any standard TIFF library.

TiffDataSource

interface TiffDataSource

Random-access byte source over a TIFF container. A tiled GeoTIFF is read block-by-block on demand — never slurped whole — so the same 2 GB orthophoto that would blow the heap as a ByteArray streams one 256×256 tile at a time through this seam.

TiffDirectory

class TiffDirectory

One parsed TIFF Image File Directory — a single raster in the file. A pyramided GeoTIFF (a COG, or anything gdaladdo has touched) holds the full-resolution image in the first IFD and each successively coarser overview in its own IFD; GeoTiffDataset keeps them as a resolution ladder and picks one per rendered tile.
