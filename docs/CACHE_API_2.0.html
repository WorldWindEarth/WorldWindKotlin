1. The orchestrator

One ContentManager per backend (gpkg file / IDB database / iOS filesystem root). Hosts many keyed content entries; the only public way to access elevation cache is through createElevationSourceFactory.

package earth.worldwind.util

interface ContentManager {
    val pathName: String
    val isReadOnly: Boolean
    val isClosed: Boolean
    suspend fun close()

    // diagnostics
    suspend fun contentSize(): Long
    suspend fun sizeBytesOf(contentKey: String): Long
    suspend fun lastModifiedDate(): Instant?

    // per-data-type creation
    suspend fun openImageTileStore(
        contentKey: String, levelSet: LevelSet,
        imageFormat: String = "image/png", isTransparent: Boolean = false,
        evictionPolicy: CacheEvictionPolicy = CacheEvictionPolicy.UNBOUNDED,
        displayName: String? = null,
    ): TileStore

    suspend fun openVectorTileStore(
        contentKey: String, levelSet: LevelSet,
        evictionPolicy: CacheEvictionPolicy = CacheEvictionPolicy.UNBOUNDED,
        displayName: String? = null,
    ): TileStore

    suspend fun openFeatureStore(
        contentKey: String,
        evictionPolicy: CacheEvictionPolicy = CacheEvictionPolicy.UNBOUNDED,
        displayName: String? = null,
    ): FeatureStore

    // elevation has its own factory entry — owns Float32 / Int16 transcoding
    suspend fun createElevationSourceFactory(
        contentKey: String, tileMatrixSet: TileMatrixSet,
        networkSource: TileSource?, outputFormat: String,
        isFloat: Boolean = false,
        evictionPolicy: CacheEvictionPolicy = CacheEvictionPolicy.UNBOUNDED,
        displayName: String? = null,
    ): ElevationSourceFactory

    // web-service metadata (infallible — implementations catch + log)
    suspend fun registerWebService(contentKey: String, info: WebServiceInfo)
    suspend fun readWebService(contentKey: String): WebServiceInfo?

    // enumeration / introspection
    suspend fun listCachedSources(): List<CachedSourceHandle>
    suspend fun findCachedSource(contentKey: String): CachedSourceHandle?

    // lifecycle
    suspend fun clearContent(contentKey: String)   // truncate tiles, keep registration
    suspend fun deleteContent(contentKey: String)  // drop everything

    // platform extension hooks (default no-op)
    suspend fun tryRecoverLevelSet(contentKey: String): LevelSet? = null
    suspend fun tryRecoverTileMatrixSet(contentKey: String): TileMatrixSet? = null
    suspend fun tryOpenNativeContent(handle: CachedSourceHandle): Any? = null
}

2. Source decorators

Bytes for tiles / vector tiles / elevation network bytes; row streams for features. The cache decorator wraps a network source + a store, serving cache-first reads with write-through on miss.

Bytes-oriented

package earth.worldwind.layer.cache

interface TileSource {
    suspend fun fetchTile(z: Int, x: Int, y: Int,
                          previousEtag: String? = null,
                          previousLastModified: String? = null): TileBlob?
    fun close() {}
}

class CachedTileSource(
    private val inner: TileSource?,
    private val store: TileStore,
) : TileSource, OfflineToggleable, CachedSourceInfoProvider {
    override var isCacheOnly: Boolean = inner == null
    override val cacheInfo: CachedSourceInfo?  // delegates to store
    // fetchTile: cache → network → write-through
}

Feature rows

interface BulkFeatureSource  { suspend fun fetchAll(): Flow<CachedFeatureRow> }
interface TiledFeatureSource { suspend fun fetchTile(z: Int, x: Int, y: Int,
                                                      sector: Sector): Flow<CachedFeatureRow>? }

class CachedBulkFeatureSource(inner: BulkFeatureSource?, store: FeatureStore)
    : BulkFeatureSource, OfflineToggleable, CachedSourceInfoProvider

class CachedTiledFeatureSource(inner: TiledFeatureSource?, store: FeatureStore)
    : TiledFeatureSource, OfflineToggleable, CachedSourceInfoProvider

3. Stores

The cache backing under the decorators. Per-platform implementations honor the same interface; eviction is enforced lazily per CacheEvictionPolicy.

interface TileStore {
    val evictionPolicy: CacheEvictionPolicy
    suspend fun readTile(z: Int, x: Int, y: Int): TileBlob?
    suspend fun writeTile(z: Int, x: Int, y: Int, blob: TileBlob)
    suspend fun deleteTile(z: Int, x: Int, y: Int)
    suspend fun evict()
    suspend fun sizeBytes(): Long
}

interface FeatureStore {
    val evictionPolicy: CacheEvictionPolicy
    suspend fun readAll(): Flow<CachedFeatureRow>
    suspend fun replaceAll(rows: Flow<CachedFeatureRow>)
    suspend fun readTile(z: Int, x: Int, y: Int): Flow<CachedFeatureRow>?
    suspend fun writeTile(z: Int, x: Int, y: Int, rows: Flow<CachedFeatureRow>)
    suspend fun evict()
    suspend fun sizeBytes(): Long
}

4. Introspection

Two layers: CachedSourceHandle for enumerating what's in the cache; cachedSourceInfo for asking a live layer "where do you store my bytes?".

What's in the cache

6. Bulk download

Same dispatch pattern for both layer types: the helper iterates (z, x, y) over a sector and resolution range, calling an interface to fetch + cache each tile. The interface differs because the underlying source models differ.

Maps — via TileSource itself

fun TiledImageLayer.launchBulkRetrieval(

    resolution: ClosedRange<Angle>,

Elevation — via a typed mixin

interface BulkRetrievableElevationSourceFactory {

7. Layer creation factories

Cache-aware factories are the recommended creation path — they wire the cache during construction, which avoids the post-factum sector / matrix validation hazards. attachCache is the escape hatch for layers built elsewhere.

Why elevation has its own factory entry on ContentManager: elevation tiles are encoded in the cache (PNG-Int16 with per-tile scale/offset, or TIFF-Float32), not raw network bytes. A generic openCoverageStore that handed out a TileStore would lure callers into wrapping it in CachedTileSource and feeding those encoded bytes through the wire-format decoder — exactly the "raw bytes through BIL16 decoder" bug class. createElevationSourceFactory hides that asymmetry behind one correct entry point.

8. Reopen — handle-driven dispatch

After restart: list cached entries → pick a handle → call openCachedLayer. The registry dispatches on (data type, service type) to the right opener; the per-platform native-content hook handles handles without a registered web service.

suspend fun ContentManager.openCachedLayer(
    handle: CachedSourceHandle,
    offlineOnly: Boolean = false,
): Any?   // the right layer/coverage class for the handle's service type

object CachedLayerRegistry {
    fun register(
        dataType: CachedSourceHandle.DataType,
        serviceType: String,
        opener: CachedLayerOpener,
    )
}

typealias CachedLayerOpener = suspend (
    contentManager: ContentManager,
    handle: CachedSourceHandle,
    offlineOnly: Boolean,
) -> Any?

9. Web-service registration

Persisted metadata that lets the reopen dispatcher reconstruct a layer without contacting the server. Capabilities XML / JSON survives across launches in WebServiceInfo.metadata.

data class WebServiceInfo(
    val type: String,           // "WMS" | "WMTS" | "WCS 1.0.0" | "WCS 2.0.1" |
                                // "MVT" | "WebMercator" |
                                // "WFS" | "Shapefile" | "OsmBuildings"
    val address: String,
    val layerName: String? = null,
    val outputFormat: String? = null,
    val metadata: String? = null,        // capabilities XML / JSON
    val isTransparent: Boolean = false,
)

10. Usage in three lines

// Create
val coverage = WmsElevationCoverage.createCoverage(
    serviceAddress = "https://elevation.example.com/wms",
    coverageName   = "DEP3Elevation",
    outputFormat   = "application/bil16",
    sector         = Sector.fromDegrees(25.0, -125.0, 25.0, 60.0),
    resolution     = Angle.fromSeconds(1.0 / 3.0),
    contentManager = cm,
    contentKey     = "elev_3dep",
    isFloat        = false,
)

// Introspect
val info: CachedSourceInfo? = coverage.cachedSourceInfo
// → CachedSourceInfo(contentKey = "elev_3dep", contentPath = "/.../OnlineCache.gpkg")

// Reopen after restart
val handle = cm.findCachedSource("elev_3dep") ?: return
val reopened = cm.openCachedLayer(handle) as? TiledElevationCoverage
Migration shape: 15 methods on ContentManager (down from 17 pre-2.0). One elevation entry point. findCachedSource returns sealed metadata. OfflineToggleable + CachedSourceInfoProvider + BulkRetrievableElevationSourceFactory are the three mixins layers look for. Nothing else.
