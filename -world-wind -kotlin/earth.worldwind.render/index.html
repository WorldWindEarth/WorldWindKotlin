open class OesExternalTexture(width: Int, height: Int) : Texture

Texture wrapper for external producers (typically Android SurfaceTexture from MediaPlayer / MediaCodec / Camera2) bound to GL_TEXTURE_EXTERNAL_OES. Storage is owned by the external producer; this class never calls glTexImage2D. Sample with the OES shader variant (samplerExternalOES) - the standard sampler2D won't bind to this target.

iOS render-resource cache with the async retrieval pipeline wired up. Mirrors the JVM version's structure: separate retrieval queues for remote (URL) vs local (resource/file) sources, an absent-resource list to suppress repeated retries on missing tiles, and an eviction queue so GL deletes happen on the GL thread (releaseEvictedResources called from WorldWindow.doFrame).
