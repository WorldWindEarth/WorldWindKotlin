iOS render-resource cache with the async retrieval pipeline wired up. Mirrors the JVM version's structure: separate retrieval queues for remote (URL) vs local (resource/file) sources, an absent-resource list to suppress repeated retries on missing tiles, and an eviction queue so GL deletes happen on the GL thread (releaseEvictedResources called from WorldWindow.doFrame).

Maximum concurrent retrievals per source category. Tuned conservatively: more than this in flight per category just thrashes the cache and buffers more half-decoded images. Increase for high-throughput tile streams; the GL thread is still the serialization point at upload time.
