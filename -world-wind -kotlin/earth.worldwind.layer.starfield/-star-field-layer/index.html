StarFieldLayer

open class StarFieldLayer(starDataSource: FileResource = AssetsMR.files.stars_json) : AbstractLayer

Constructs a layer showing stars and the Sun around the Earth. If used together with the AtmosphereLayer, the StarFieldLayer must be inserted before the AtmosphereLayer.

If you want to use your own star data, the file provided must be .json and the fields "ra", "dec" and "vmag" must be present in the metadata. ra and dec must be expressed in degrees.

This layer uses J2000.0 as the ref epoch.

If the star data .json file is too big, consider enabling gzip compression on your web server. For more info about enabling gzip compression consult the configuration for your web server.
