actual open class ElevationSource : AbstractSource

Provides a mechanism for specifying elevations from a variety of sources.
ElevationSource supports following source types:

  • Uniform Resource Locator URL

  • Local image File

  • WorldWind ElevationSource.ElevationDataFactory
    ElevationSource instances are intended to be used as a key into a cache or other data structure that enables sharing of loaded elevation resources. File paths and URLs with the same string representation considered equals.
