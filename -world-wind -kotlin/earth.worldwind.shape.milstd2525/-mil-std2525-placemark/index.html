MilStd2525Placemark

actual open class MilStd2525Placemark(symbolID: String, position: Position, symbolModifiers: Map<String, String>?, symbolAttributes: Map<String, String>?, lodSelector: Placemark.LevelOfDetailSelector) : AbstractMilStd2525Placemark

Constructs a MIL-STD-2525 Placemark with an appropriate level of detail for the current distance from the camera. Shared low-fidelity images are used when far away from the camera, whereas unique high-fidelity images are used when near the camera. The high-fidelity images that are no longer in view are automatically freed, if necessary, to release memory resources. The Placemark's symbol is lazily created (and recreated if necessary) via an ImageSource.ImageFactory. See the MilStd2525Placemark.getPlacemarkAttributes for more information about resource caching/sharing and the bitmap factory.
