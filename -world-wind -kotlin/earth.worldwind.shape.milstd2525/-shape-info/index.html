ShapeInfo

open external class ShapeInfo : JsAny

Holds information on how to draw the pieces of a multipoint symbol. Can be retrieved from {@link MilStdSymbol#getSymbolShapes()} and {@link MilStdSymbol#getModifierShapes()} after {@link armyc2.c5isr.web.render.WebRenderer#RenderMultiPointAsMilStdSymbol(String, String, String, String, String, String, double, String, Map, Map)} is called.
