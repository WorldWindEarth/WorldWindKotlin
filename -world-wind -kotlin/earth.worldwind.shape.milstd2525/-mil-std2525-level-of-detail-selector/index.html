MilStd2525LevelOfDetailSelector

open class MilStd2525LevelOfDetailSelector : Placemark.LevelOfDetailSelector

The MilStd2525LevelOfDetailSelector determines which set of PlacemarkAttributes to use for a MilStd2525Placemark. A MilStd2525Placemark creates an instance of this class in its constructor, and calls Placemark.LevelOfDetailSelector.selectLevelOfDetail in its Placemark.doRender method.

The selection is remembered per rendering window: several windows may render the same placemark in the same choreographer pass with different camera distances and fill modes, and must not discard each other's selection.
