PointCloudContent

class PointCloudContent : TileContent

GPU-resident point cloud content for a single pnts tile. Single VBO with interleaved [posX, posY, posZ, colorR, colorG, colorB, colorA] (7 floats = 28 bytes per point). Color is normalized to 0, 1 floats at parse time to keep the shader path simple.

Lifecycle:

  1. preparePointCloudContent runs off the render thread on the parse coroutine, interleaves position + colour into interleavedVertices, and computes the local bounding sphere.

  2. syncPointCloudContentGpu runs each render frame, looking up the VBO from the cache and re-uploading interleavedVertices when the cache has dropped it. The CPU-side payload stays alive on the content for this re-upload path.

4x memory overhead vs packed uint8 RGBA, but the all-float layout means we reuse the existing NumericArray.Floats upload pipeline without introducing a Bytes variant.
