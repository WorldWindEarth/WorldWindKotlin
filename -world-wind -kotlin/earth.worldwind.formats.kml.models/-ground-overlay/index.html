GroundOverlay

@Serializable
data class GroundOverlay(val id: String? = null, val altitude: Double = 0.0, val altitudeMode: AltitudeMode = AltitudeMode.clampToGround, val latLonBox: LatLonBox? = null, val latLonQuad: LatLonQuad? = null) : Overlay

This element draws an image overlay draped onto the terrain. The child of Icon specifies the image to be used as the overlay. This file can be either on a local file system or on a web server. If this element is omitted or contains no , a rectangle is drawn using the color and LatLonBox bounds defined by the ground overlay.
