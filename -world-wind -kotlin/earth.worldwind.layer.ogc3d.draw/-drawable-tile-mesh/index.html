DrawableTileMesh

open class DrawableTileMesh : Drawable, ShadowCaster, SightlineOccluder, GroundOverlaySurface

Color-pass drawable for one mesh tile. Pool-recycled. ShadowCaster + SightlineOccluder gate on shadowMode.castsShadows. The sightline visibility tint is applied per-fragment by Ogc3dTilesProgram's embedded SightlineReceiverGlsl splice; the SURFACE-grouped sightline overlay only tints terrain.
