DrawableTilePoints

open class DrawableTilePoints : Drawable, ShadowCaster

Color-pass drawable for one 3D Tiles point cloud tile. Holds a reference to the pre-uploaded PointCloudContent, the tile-to-world transform, and per-frame state for the shadow + sightline receiver paths. Pool-recycled.

Casts cascade shadows as 1-pixel point splats: the depth-only caster program is triangle-oriented but happily rasterises GL_POINTS, with gl_PointSize defaulting to 1. Softened by the receiver's PCF, dense LiDAR clouds produce believable ground-halo shadows; sparse clouds look slightly stippled. A follow-up may add a dedicated points depth program that writes a size-attenuated gl_PointSize matching the colour pass's per-splat disc.
