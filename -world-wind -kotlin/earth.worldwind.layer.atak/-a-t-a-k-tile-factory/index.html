clearEntry

open suspend override fun clearEntry(deleteMetadata: Boolean = false)

Clear cached tiles for this entry. With deleteMetadata = true, also drop the service-identity row (and, for file-format factories, the underlying file) so the entry is gone for good. With false (default), the registration / catalog row survives so re-download repopulates the same layer without re-configuration.
