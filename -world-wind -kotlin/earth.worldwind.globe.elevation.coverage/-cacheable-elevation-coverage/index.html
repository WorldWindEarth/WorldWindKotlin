CacheableElevationCoverage

interface CacheableElevationCoverage : ElevationCoverage

Marker for elevation coverages backed by a tile pyramid. Cache integration is composed externally — wrap the elevation source with a cache-aware decorator (mirrors the earth.worldwind.layer.cache.CachedTileSource pattern used by image layers).
