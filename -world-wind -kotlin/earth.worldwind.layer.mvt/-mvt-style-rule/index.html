MvtStyleRule

class MvtStyleRule(val sourceLayer: String, val filter: MvtFilter = MvtFilter.Always, val minZoom: Int = 0, val maxZoom: Int = Int.MAX_VALUE, val zOrder: Int = 0, val geometryType: MvtGeometryType? = null, val paint: MvtStyleRule.PaintSpec)

One declarative rule in an MvtRuleBasedStyle. Matches features by source layer name, optional filter over properties, and tile-zoom range, then resolves zoom-interpolated paint properties into a ShapeAttributes.

Rules paint in declaration order — earlier rules in the list paint under later rules. The zOrder field also feeds MvtStyle.zOrderFor so cross-tile compositing matches the within-tile order.

Parameters

sourceLayer

MVT layer name to match (e.g. "streets", "water_polygons"). Use MvtStyle.zOrderFor canonicals where they apply.

filter

predicate over the feature's property map; defaults to MvtFilter.Always.

minZoom

smallest tile zoom that activates this rule (inclusive); below = skipped.

maxZoom

largest tile zoom that activates this rule (inclusive); above = skipped. Int.MAX_VALUE = no upper bound.

zOrder

paint order against rules in other tiles. Use MvtStyle.Z_* constants.

geometryType

when non-null, only matches features of that geometry type. Useful for splitting a layer that carries both polygon and line variants (e.g. Shortbread's street_polygons vs streets).

paint

resolves zoom-interpolated paint properties into a ShapeAttributes.
