LasPointCloud

class LasPointCloud

Decoded standalone point cloud from a LAS/LAZ file. Positions are in the file's native CRS (see crs); georeferencing to the globe is the earth.worldwind.layer.pointcloud.PointCloudLayer's job. Colours are always 8-bit RGBA — from the file's RGB channels when present, else a grayscale ramp synthesized from intensity so every cloud renders visibly.
