var shadowMode: ShadowMode

Cast/receive selector for cascaded sun shadows. Default ShadowMode.ENABLED = scene both casts onto terrain/other receivers and receives shadows on its own surface. Common opt-out: ShadowMode.RECEIVE_ONLY to drop the cascade depth pass for HUD-style or self-lit models that look wrong projected onto the ground.

invalidate
Link copied to clipboard
fun invalidate()

Marks the cached world transform and ray-intersection geometry stale so they are rebuilt on the next render/pick. Assigning position, altitudeMode, the rotation/translation/scale properties already calls this; invoke it manually only after mutating one of them in place — e.g. correcting a KMZ model's altitude via scene.position.altitude += offset; scene.invalidate(). Terrain inputs (vertical exaggeration, and for terrain-relative modes the elevation timestamp / globe state) trigger it automatically via checkTerrainState so the model follows the resolved terrain.
