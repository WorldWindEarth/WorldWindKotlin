TilesetAuthProvider
Link copied to clipboard
interface TilesetAuthProvider

Plugged into every HTTP fetch a 3D Tiles layer makes: the root tileset.json, every external tileset reference, and every content payload. Providers can rewrite the URL (e.g. append a query parameter), append request headers, or both. They are also given the chance to mutate child URIs at parse time via rewriteChildUri so persistent state like Google's session token rides down the tree.
