CompositeAuthProvider

class CompositeAuthProvider(providers: List<TilesetAuthProvider>) : TilesetAuthProvider

Chains multiple providers so callers can stack auth (e.g. Ion bearer token + internal tracing headers). Providers are applied in order; each one sees the URL + headers produced by the previous one.
