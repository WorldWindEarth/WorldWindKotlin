ShapefileRecord

class ShapefileRecord

One parsed shapefile record. Records of all shape types are represented by this single class; the shapeType field discriminates. Geometry is exposed as a list of "parts", each part an interleaved [x0, y0, x1, y1, …] DoubleArray matching the on-disk coordinate order (longitude, latitude for geographic shapefiles).
