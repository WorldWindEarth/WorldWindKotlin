BasicWorldWindowController

open class BasicWorldWindowController(wwd: WorldWindow) : AbstractWorldWindowController, WorldWindowController, GestureListener

iOS port of the gesture-driven camera controller. Mirrors the Android shape — own a set of recognizers, dispatch TouchEvents, translate gestureStateChanged into camera updates.

fling
Link copied to clipboard
val fling: FlingAnimator

Inertial pan animator. Each platform's createFlingScheduler supplies the per-frame clock. The per-frame action dispatches by projection: 2D uses incremental projected-meters math, 3D uses great-circle radians. Picking the right one matters because Mercator metersPerPixel diverges from the 3D radians-on-a-sphere formula away from the equator.
