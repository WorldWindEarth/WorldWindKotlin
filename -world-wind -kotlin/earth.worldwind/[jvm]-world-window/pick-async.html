pickAsync

fun pickAsync(x: Double, y: Double, width: Double = 0.0, height: Double = 0.0, pickCenter: Boolean = true): Deferred<PickedObjectList>

Determines the WorldWind shapes displayed in a screen rectangle. The screen rectangle is interpreted as GL viewport coordinates. Use viewportCoordinates to convert Swing screen pixels to GL viewport coordinates before calling this method.

Return

a deferred list of WorldWind shapes in the screen rectangle

Parameters

x

the screen rectangle's X coordinate in GL viewport pixels

y

the screen rectangle's Y coordinate in GL viewport pixels

width

the screen rectangle's width in GL viewport pixels

height

the screen rectangle's height in GL viewport pixels

pickCenter

picks top shape and terrain in rectangle center as priority
