pick
Link copied to clipboard
fun pick(x: Float, y: Float, width: Float = 0.0f, height: Float = 0.0f, pickCenter: Boolean = true): PickedObjectList

Synchronous variant of pickAsync. iOS has no separate GL thread, so we drain the pick frame inline on the main thread - the same model JVM's SelectDragDetector relies on (it wraps pickAsync in runBlocking). Without this, async pick-during-DOWN leaves a window where the navigation controller can start panning before we know whether the gesture should drag a renderable.
