I3sSceneLayer

object I3sSceneLayer

DTOs + decoders for the I3S documents a tile tree is built from: 3dSceneLayer.json and node pages (nodepages/{n}.json). Scope: I3S 1.7+ compact form (node pages) for the hierarchy; legacy 1.6 per-node 3dNodeIndexDocuments are consulted only for texture names when a package omits textureSetDefinitions. Only consumed fields are modelled; unknown keys ignored.
