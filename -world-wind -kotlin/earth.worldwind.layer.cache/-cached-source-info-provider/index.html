CachedSourceInfoProvider

interface CachedSourceInfoProvider

Mixin for cache-aware sources, factories, and stores that can report their underlying CachedSourceInfo. Implementations:

  • The per-platform TileStore implementations (gpkg, IDB, filesystem).

  • CachedTileSource delegates to its inner store.

  • The elevation source factories (GpkgCachedElevationSourceFactory on JVM, CachedElevationSourceFactory on JS / iOS) report from their content / backend.

Apps that want a layer's contentKey for bulk-download progress, "save offline" UI, or cache inspection use the layer-side extensions; this interface is the underlying mechanism, not an app-facing surface.
