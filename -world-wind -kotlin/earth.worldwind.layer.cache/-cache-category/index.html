CacheCategory

sealed class CacheCategory<out T : Any>

Typed key for bulk-opening cached content by category. The phantom T carries the return type all the way from the call site through earth.worldwind.util.open, so cm.open(CacheCategory.Tiles) returns List<TiledImageLayer> with no as? cast and no reified type argument at the call site.

For narrower filters than a whole category (e.g. only WMS image layers), keep the returned list and add a .filterIsInstance<WmsImageLayer>() — there's no per-subtype key, because CacheCategory is intentionally coarse.
