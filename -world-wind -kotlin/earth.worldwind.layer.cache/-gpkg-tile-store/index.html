GpkgTileStore

class GpkgTileStore(geoPackage: GeoPackage, content: GpkgContent, val cachePolicy: CachePolicy = CachePolicy.UNBOUNDED) : TileStore, CachedSourceInfoProvider

GeoPackage-backed TileStore. One instance binds to one tile-pyramid table — works for any data_type that uses the tile-user-data shape (image/png, image/jpeg, image/webp, gridded coverages, vector-tile protobuf).

(z, x, y) maps to (zoom_level, tile_column, tile_row). ETag / Last-Modified ride alongside in the ww_tile_revalidation side table, so a conditional GET against the network source on a follow-up refresh stays cheap.

Tile-payload format is whatever the source produced — the store doesn't decode. Image layers decode PNG/JPEG/WebP at render time; elevation layers decode the gridded blob; MVT layers parse the protobuf.
