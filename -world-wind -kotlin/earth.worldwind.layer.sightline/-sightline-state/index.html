SightlineState

class SightlineState

Per-frame snapshot of the active directional / omnidirectional sightline so receiver programs can sample the sightline depth cube in their own fragment shader (parallel to earth.worldwind.layer.shadow.ShadowState).

Populated by earth.worldwind.draw.DrawableSightline after its depth pass, before any receiver renders. Read by drawables that opt in via SightlineReceiverProgram and the applySightlineReceiverUniforms helper. null between frames and on frames without an enabled sightline; receivers must treat a null state as "no sightline".
