NitfImageSegment

class NitfImageSegment

Parsed subheader for one NITF/NSIF image segment. The image data (the pixel grid itself, possibly preceded by a block mask) is not decoded here — see NitfImageReader.decodeArgb / NitfImageReader.decodeRaw.

Fields follow MIL-STD-2500C §5.4 and use the spec acronyms in the doc comments so the source is easy to cross-reference with the standard.
