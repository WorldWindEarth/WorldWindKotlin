ImplicitTilingDescription

@Serializable
class ImplicitTilingDescription(val subdivisionScheme: SubdivisionScheme = SubdivisionScheme.QUADTREE, val subtreeLevels: Int = 1, val availableLevels: Int = 1, val subtrees: ImplicitUriTemplate = ImplicitUriTemplate())

3D Tiles 1.1 implicit-tiling metadata. Replaces explicit per-tile JSON declarations with a coordinate-derivable tree: every (level, x, y, z) within availableLevels potentially has a tile, and on-demand .subtree availability bitstreams say which coordinates are actually populated.

Spec: https://github.com/CesiumGS/3d-tiles/tree/main/specification/ImplicitTiling.
