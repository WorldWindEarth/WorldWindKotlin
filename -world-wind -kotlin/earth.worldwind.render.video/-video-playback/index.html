VideoPlayback

interface VideoPlayback

Common playback contract for the JVM video textures (VLCJ, JavaCV, FFmpeg, JavaFX). Every JVM *VideoTexture exposes the same minimal API; this interface formalizes that so tutorial / app code can target one type instead of carrying a per-backend adapter.

The engine doesn't depend on this interface — it's a convenience for callers that want to swap backends at runtime.
