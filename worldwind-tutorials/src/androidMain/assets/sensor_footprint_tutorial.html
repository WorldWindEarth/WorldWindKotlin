Sensor Footprints Tutorial

Drones circle over Mount St. Helens, each with a framing camera, and where each frame meets the ground is outlined as the drones fly: ten to start with, up to a thousand with the More drones and Fewer drones buttons. The frame rate and drone count are shown in the top left corner.

The frames are drawn by a SensorFrameOverlay, entirely on the GPU, like sun shadows with the camera as the sun: the terrain is drawn once more and every pixel along the edge of a camera's frame is tinted, so each outline follows the hills exactly. The CPU only builds one matrix per drone, so every frame follows its drone every frame, wherever the map looks.

  • Cheap where it matters — each draw is scissored to the screen rectangle its frames' ground can cover, and pixels outside a frame are rejected with a few comparisons before any division.
  • Fill and occlusion — the overlay can also fill the frames, and with occlusion on (a small depth map rendered from each drone, like a shadow map) tint the ground a drone sees apart from ground behind a ridge. This tutorial draws the outlines only.
