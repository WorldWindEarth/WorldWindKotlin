WMS Layer Tutorial

Demonstrates how to display an OGC Web Map Service (WMS) layer.

This example adds a surface-temperature WMS layer to the basic globe example.

Example

WmsLayerFragment.kt

WmsLayerFactory.createLayer negotiates capabilities with the WMS endpoint, derives a LevelSet from the advertised bounding box / coordinate system, builds a WmsTileSource, and returns a TiledImageLayer. Resolving capabilities is what tells us how big the tile pyramid is — but the cache needs that LevelSet up-front to size its tile-matrix table. That chicken-and-egg is solved by the cacheBinder callback: the factory invokes it after capabilities resolution with the resolved LevelSet + image format, and the caller returns a TileStore sized exactly to those dimensions. If the binder returns non-null the factory wraps the network WmsTileSource in a CachedTileSource automatically.
