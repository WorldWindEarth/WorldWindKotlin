OGC 3D Tiles Tutorial

Streams a public OGC 3D Tiles 1.0 photogrammetry dataset (Utrecht integrated mesh) into the globe via Ogc3dTilesLayer. The tutorial wires a GeoPackage-backed BlobStore for persistent caching; switch the endpoint or auth provider (e.g. Google Photorealistic via GoogleTilesAuthProvider) by changing the layer constructor — no other code changes needed.
