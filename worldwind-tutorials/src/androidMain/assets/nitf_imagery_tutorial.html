NITF Imagery Tutorial

Demonstrates the National Imagery Transmission Format (NITF 2.1 / NSIF 1.0) reader. The tutorial synthesises a small RGB NITF (256 × 256 px, 8 × 8 grid of 32-px blocks, IC=NC, IMODE B) in memory at startup, parses it with the shared Nitf + NitfImageReader APIs, and drapes the decoded pixels over Mt Etna as a SurfaceImage.

The parser is fully cross-platform (lives in commonMain on top of BinaryDataView). The only per-platform piece is NitfImage.toImageSource(), which builds the native bitmap (BufferedImage on JVM, Bitmap on Android, ImageBitmap on JS, UIImage on iOS).

Phase 1 scope

  • NITF 2.1 + NSIF 1.0 file header and image segment subheaders.
  • IGEOLO decoding for G (DMS), D (decimal degrees), and N/S (UTM).
  • Uncompressed pixel data: IC=NC and IC=NM with block masks.
  • All four IMODE values (B, P, R, S).
  • NBPP ∈ {8, 16}, NBANDS ∈ {1, 3, 4}, IREP ∈ {MONO, RGB, RGB/LUT, MULTI}.

JPEG (IC=C3/M3), JPEG 2000 (IC=C5/C8/M5), VQ (IC=C4) and the GeoPackage tiling path for very large NITFs are scheduled for later phases.

Example

NitfImageryFragment.kt

The fragment extends BasicGlobeFragment and starts the shared NitfImageryTutorial against the engine. The tutorial itself lives in commonMain so JVM, Android, JS, and iOS share the same code path.
