Vector Tiles (MVT) Tutorial

Demonstrates MvtVectorLayer — Mapbox Vector Tile (MVT) data fetched from Versatiles' public CDN (OpenMapTiles v3 schema, no API key) and styled client-side with OpenTopoMapRules to approximate an OpenTopoMap look. Tiles are decoded locally: protobuf payload → command-stream geometry → Web-Mercator unprojection → batched polygons (one VBO+EBO per tile) and batched lines.

Tile zoom auto-tracks camera altitude (selectTileZoom) and z-order between features is honoured via MvtStyle.zOrderFor — water under landuse under buildings under roads, etc. Drop in your own MvtStyle to customise colours and z-order.

The MVT byte stream uses the same TileSource abstraction as image tiles: UrlTemplateMvtTileSource is the network source, CachedTileSource(networkSource, store) decorates it with write-through persistence into a GeoPackage vector-tile store. The layer is unaware of the cache — it just calls fetchTile(z, x, y) on the source it was given.
