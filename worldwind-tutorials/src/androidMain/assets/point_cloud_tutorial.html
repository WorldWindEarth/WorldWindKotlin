Point Cloud (LAS/LAZ) Tutorial

Loads a standalone LiDAR point cloud with PointCloudLayer and renders it as size-attenuated GL_POINTS splats. The sample is the public Autzen Stadium scan (~694k RGB points, point format 3, compressed .laz). Compressed .laz decoding is enabled by installing LasDecoderRegistry.lazDecoder = LaszipDecoder(); plain .las needs no decoder.

The file is genuinely georeferenced (EPSG:26910, NAD83 UTM 10N), which the loader auto-detects, so the cloud lands on its real location and real elevation with no projection hook. It rests on the globe's terrain (elevation is enabled on start) and overlays the matching satellite imagery — that overlay is the correctness check.
