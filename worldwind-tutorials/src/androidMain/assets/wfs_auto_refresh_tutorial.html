WFS Auto-Refresh Tutorial

Demonstrates viewport-driven loading from an OGC Web Feature Service (WFS) with WfsLayer.autoRefresh. The WFS Layer tutorial fetches a small feature set once; this one points at a large layer (opengeo:countries) that would exhaust memory if fetched whole.

With autoRefresh = true, the layer inspects the visible extent (rc.terrain.sector) each frame and, when the viewport leaves the previously fetched (padded) sector, schedules a debounced background fetch of a BBOX-bounded, COUNT-capped page for what's on screen. The fetch builds renderables off the render thread and the next frame swaps them in, so memory stays bounded as you pan and zoom. Because WfsLayer lives in commonMain, the whole tutorial is shared across platforms with no per-platform layer loader.
