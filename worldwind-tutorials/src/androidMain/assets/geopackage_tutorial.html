GeoPackage Tutorial

Demonstrates how to open every cached layer / coverage stored in a GeoPackage and add each one to the engine.

Every cache-writing layer (WMS, WMTS, MVT, WCS, WFS, Shapefile, OSM Buildings, XYZ-templated image) records its web-service metadata under gpkg_web_service when its store is first populated. ContentManager.open(category) walks the catalog and rebuilds every entry in that category — image layers, vector layers, feature layers, or elevation coverages — as fully wired instances ready to be added to the engine.

This tutorial opens the bundled geopackage_tutorial.gpkg in read-only mode and pulls every cached layer / coverage via the typed bulk-open helpers. The bundled file has no live server twin, so each result is flipped into strict cache-only mode with setOfflineOnly() — cache misses return nothing, never network.
