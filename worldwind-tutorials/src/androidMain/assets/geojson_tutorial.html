GeoJSON Tutorial

Demonstrates loading a GeoJSON document through the v3 BulkFeatureLayer pipeline.

GeoJsonBulkFeatureSource parses the document into CachedFeatureRows on demand; BulkFeatureLayer renders each row, applying GeoJSON simplestyle keys (stroke / fill / stroke-width / icon / …) automatically before the customLogicToApplyProperties lambda runs. GeoJsonLayerFactory.createLayer(text, …) is the convenience facade.

The sample document holds three European countries (UK as a MultiPolygon, France and Spain as plain Polygons), a GeometryCollection for a mountain range, and six cities. Each feature carries a population attribute; the lambda tints placemarks, labels, and polygons by population tier on top of the simplestyle defaults. The UK's MultiPolygon fans out to two Polygon renderables that share the same properties map — the lambda runs once per renderable, so both pieces get the same tint.
