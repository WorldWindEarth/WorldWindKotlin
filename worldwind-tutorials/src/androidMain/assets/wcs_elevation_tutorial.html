WCS Elevation Coverage Tutorial

Demonstrates how to add an OGC Web Coverage Service (WCS) elevation coverage.

This tutorial loads USGS 3DEP elevation data from a WCS 1.0.0 endpoint.

Example

WcsElevationFragment.kt

Elevation tiles flow through the same TileSource abstraction as image tiles. Internally Wcs100ElevationTileSource builds a GetCoverage URL for each (z, x, y), and TileSourceElevationSourceFactory bridges those byte blobs into the engine's existing ElevationSourceFactory contract (which decodes GeoTIFF / BIL16 into a tile of floats).

The fragment builds a network-only Wcs100ElevationCoverage synchronously, then calls attachCache from a coroutine. That extension opens the GPKG coverage store sized to the coverage's tileMatrixSet, wraps the network tile source in CachedTileSource, and swaps the live elevationSourceFactory in-place — matching the same attach-pattern the basic globe uses for Google Satellite + NASADEM.
