WMTS Layer Tutorial

Demonstrates how to display an OGC Web Map Tile Service (WMTS) layer.

This example adds a hillshade WMTS layer to the basic globe example.

Example

WmtsLayerFragment.kt

WmtsLayerFactory.createLayer reads the WMTS Capabilities document, selects a TileMatrixSet and tile format, and builds a WmtsTileSource that substitutes {TileMatrix}, {TileRow}, and {TileCol} placeholders into the advertised URL template. Like WMS, the cache is wired via cacheBinder: it fires after capabilities resolution with the derived LevelSet + image format, and a non-null return triggers the factory to wrap the network source in CachedTileSource.
