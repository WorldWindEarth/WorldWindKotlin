Shapefile Layer Tutorial

Demonstrates how to load an ESRI Shapefile (.shp + .dbf + .prj) and display its features as a RenderableLayer.

ShapefileLayerFactory fetches the .shp file at the supplied URL plus the .dbf and .prj sidecars (auto-derived by extension), parses them, and creates Path / Polygon / Placemark renderables. A per-record shapeConfiguration callback customizes attributes, labels, altitude, or extrusion.
