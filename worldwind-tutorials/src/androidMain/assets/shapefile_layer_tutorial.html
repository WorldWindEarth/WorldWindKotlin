Shapefile Layer Tutorial

Demonstrates how to load an ESRI Shapefile (.shp + .dbf + .prj) and display its features as a RenderableLayer.

ShapefileBulkFeatureSource fetches the .shp file at the supplied URL plus its .dbf / .prj / .cpg sidecars (auto-derived by extension) and parses every record. BulkFeatureLayer consumes the source — the same consumer used by WFS, since the row format is identical. contentManager.attachCache(layer, contentKey) wraps the source in the cache decorator and registers a "Shapefile" service-identity row so subsequent launches replay from the GeoPackage feature store.
