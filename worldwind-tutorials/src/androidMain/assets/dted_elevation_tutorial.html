DTED Elevation Coverage Tutorial

Demonstrates how to mount a local directory of DTED (Digital Terrain Elevation Data, MIL-PRF-89020B) tiles as an elevation coverage using DtedElevationCoverage.

By default, the tutorial synthesises a small 3×3 grid of DTED-0 tiles (121×121 posts each, ~30 KB per file) into a temp directory at startup — a sharp summit over a broad massif with faint ridges — so the elevation pipeline is exercised end-to-end without needing a real DTED CD. Set the DTED_DIR system property to point at a real local DTED library instead; the directory is scanned recursively and tiles named per the NIMA n45/e034.dt1 or n45e034.dt1 convention are indexed without opening any UHL headers.

Example

DtedElevationFragment.kt

The fragment extends BasicGlobeFragment and starts the shared DtedElevationTutorial against the engine. The tutorial itself lives in the JVM/Android-shared jvmCommonMain source set so the JVM desktop host and Android host run the same code.
