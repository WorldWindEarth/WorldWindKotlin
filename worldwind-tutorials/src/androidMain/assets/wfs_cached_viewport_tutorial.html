WFS Cached (Viewport) Tutorial

Demonstrates Strategy 1 — download-once cache — over a bounded WFS polygon layer (opengeo:countries).

contentManager.attachCache(layer, key) wraps the WfsBulkFeatureSource in a CachedBulkFeatureSource over a GeoPackage store. On the first viewport read the whole layer is downloaded once into the store (built with an RTree spatial index); thereafter autoRefreshViewport serves each pan/zoom as a BBOX query from the local index, so RAM holds only the visible features and the layer works offline. Use this for bounded, fairly static layers; a layer too large to download whole should use the tiled cache-through tutorial instead.
