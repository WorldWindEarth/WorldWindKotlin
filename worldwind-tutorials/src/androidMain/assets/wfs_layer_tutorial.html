WFS Layer Tutorial

Demonstrates how to display an OGC Web Feature Service (WFS) layer.

WfsLayerFactory negotiates a compatible output format with the WFS endpoint (preferring GeoJSON, falling back to GML 3.2 / 3.1), fetches features via GetFeature, and produces a RenderableLayer. This tutorial also shows two of the factory's hooks: pageSize triggers WFS 2.0 STARTINDEX pagination so large datasets come back in chunks, and customLogicToApplyProperties runs once per parsed feature so callers can style placemarks/paths/polygons from the server's attributes.
