WFS Layer Tutorial

Demonstrates how to display an OGC Web Feature Service (WFS) layer.

WfsBulkFeatureSource negotiates a compatible output format with the WFS endpoint (preferring GeoJSON, falling back to GML 3.2 / 3.1) and fetches features via GetFeature. BulkFeatureLayer consumes the source and runs the supplied customLogicToApplyProperties styling lambda over every rebuilt renderable. contentManager.attachCache(layer, contentKey) wraps the source in the cache decorator and registers a service-identity row, so subsequent launches can rediscover the same layer through listEntries() / openLayer<BulkFeatureLayer>.
