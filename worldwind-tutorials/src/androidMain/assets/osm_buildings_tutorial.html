OSM Buildings Tutorial

Demonstrates OsmBuildingsLayer — schematic 3D buildings rendered live from OpenStreetMap. Footprints and height tags are fetched from the public Overpass API for the visible region (slippy-tile pyramid, on-demand), then extruded client-side into gray polygons. Visually similar to Cesium OSM Buildings, but fully open and key-less.

The camera is parked over midtown Manhattan, which is densely and well-tagged. The first frame is empty: tiles arrive asynchronously and the layer redraws as each one completes. Public Overpass mirrors rate-limit aggressively — for production traffic, point the layer at a self-hosted endpoint via OverpassBuildingsSource(endpoint = …).
