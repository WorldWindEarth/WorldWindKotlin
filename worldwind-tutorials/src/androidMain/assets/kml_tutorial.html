KML Tutorial

Loads a small KML document via KmlLayerFactory.

The sample document defines two shared <Style> blocks (an icon style and a line+poly style) and references them from three placemarks (London / Paris / Brussels) plus one polygon that connects the three. The factory parses the XML, resolves <styleUrl> references against the document, and emits one RenderableLayer per <Document> / <Folder>.
