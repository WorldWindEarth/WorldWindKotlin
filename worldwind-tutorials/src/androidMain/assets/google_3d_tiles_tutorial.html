Google 3D Tiles Tutorial

Streams Google's Photorealistic 3D Tiles — the same globe-scale photoreal mesh that powers Google Earth — via the Map Tiles API. GoogleTilesAuthProvider propagates the per-session session= token down the tile tree automatically; the layer also auto-enables the Google-specific node-matrix unpacking and skip-rotation pair when it sees this auth provider.

Paste your Google Maps API key into GoogleOgc3dTilesTutorial.googleApiKey (Map Tiles API must be enabled in the GCP console).
