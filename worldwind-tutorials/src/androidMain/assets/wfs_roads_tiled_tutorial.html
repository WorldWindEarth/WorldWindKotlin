WFS Roads (Tiled Cache) Tutorial

Demonstrates Strategy 2 — tiled cache-through — over a dense GLOBAL WFS line layer (ne:ne_10m_roads, ~57k features worldwide) that must NOT be fetched whole. Each tile's GetFeature returns the full, unclipped geometry of every road that intersects it, so whole roads render — the tile only bounds the fetch. Many features per tile exercises the batched line/outline path; major highways are drawn brighter and thicker than minor roads.

WfsTiledFeatureSource issues one GetFeature per slippy-map tile (bounded by the tile's BBOX, capped at maxFeaturesPerTile). TiledFeatureLayer drives tile selection from the viewport (centre-spiral, LRU) and renders generic features via FeatureRenderer. contentManager.attachCache(layer, key) wraps the source in CachedTiledFeatureSource over a GeoPackage store, so each tile is cached on first fetch and served from the local RTree on revisit — both memory and network stay bounded, and visited areas work offline. A coarser level floor (levelOffset = 2) keeps the layer visible across a wider range of camera tilt than the polygon demo.
